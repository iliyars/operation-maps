# Roadmap

Контекст: WPF-приложение для подготовки карт эксплуатации электронных
компонентов (импорт XML → сопоставление с каталогом → редактирование форм →
экспорт в Word по ГОСТ-шаблонам). Сейчас используется небольшой командой,
в далёкой перспективе возможен переход в коммерческий продукт.

Статус: ранняя стадия, архитектура и функциональность ещё активно меняются.

Этапы идут по приоритету, без привязки к датам. Внутри этапа порядок пунктов
не строгий — можно брать то, что сейчас удобнее.
