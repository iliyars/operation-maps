# Примечания к параметрам

Отдельный выбор режимов в интерфейсе проекта удалён. Единственное примечание,
которое меняет значение параметра, — «облегчённый режим» (включая формы
«используется в облегчённом режиме» и написание с е вместо ё).

При импорте Word такое примечание связывается с прочитанным значением.
Остальные примечания остаются пояснениями и не переключают значения.
Отдельная классификация примечаний пользователем не требуется.

В форме 4 у соответствующего параметра есть флажок с сохранённым примечанием
и значением. Его выбор подставляет значение облегчённого режима; снятие
возвращает обычное. Если обычное значение не было задано, показывается «—».
Оно не выдумывается.

Один параметр может иметь отдельные значения для нормального и облегчённого
режима: например, ресурс 100000 ч и 150000 ч. В каталоге сохраняются оба
значения; переключение условия меняет применяемое значение, не удаляя второе.

Если облегчённое значение задано, но нормальное отсутствует, компонент
получает пометку **«Необходимо редактирование»**. Пустая строка, прочерк,
вопросительный знак и «неизвестно» не считаются нормальным значением.
Пометка содержит форму, строку и название параметра; она видна в списке
компонентов проекта, списке/карточке справочника и проверке перед экспортом.
Она действует независимо от обязательности параметра и прежнего подтверждения
компонента. Применение облегчённого режима не устраняет недостаток исходных данных.

Нормальное значение можно заполнить в базовых данных НТД либо сохранить
отдельным обычным вариантом значения через редактор условий. После исправления
справочник пересчитывает пометку. Подтвердить запись с отсутствующим нормальным
значением как проверенную нельзя; это проверяется и в UI, и в сервисе записи.

Проверка экспорта также требует заполнения обязательных значений.
Если два примечания задают разные значения одного параметра, сначала нужно
снять предыдущее. Измеренные значения «в схеме» остаются самостоятельными.

Выбранное значение и обязательный текст примечания сохраняются вместе в проекте
и выводятся в Word. Снятие примечания не удаляет запись из каталога.

Имена старых таблиц ComponentRegimes/ComponentRegimeValues и полей .omaps
сохранены для совместимости: это техническое хранение вариантов значений,
а не отдельный пользовательский механизм режимов. Существующие данные не удаляются.
Ранее импортированные варианты облегчённого режима доступны в форме 4 без
повторного импорта. Старые произвольные режимы не переклассифицируются автоматически.

Формат проекта — версия 4, чтение версий 1–3 поддерживается.
При разрешении конфликта объединения явно выбранные условия собственного
столбца (включая выбор базовых значений без условия) сохраняются отдельно
от унаследованного выбора компонента. Повторное открытие не заменяет их
условиями исходного компонента. Ранее выпущенная программа с поддержкой
только версии 3 попросит обновление при открытии нового файла.
