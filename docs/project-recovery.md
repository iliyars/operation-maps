# Автовосстановление проекта

Приложение раз в минуту записывает аварийную копию открытого проекта,
если в нём есть несохранённые изменения. Между копиями изменения за последнюю
минуту могут быть потеряны при сбое — обычное сохранение проекта по-прежнему нужно.

Копии хранятся в `%LocalAppData%\OperationMaps\Recovery`, отдельно от `.omaps`
и общей базы каталога. Запись копии не меняет путь проекта и не снимает признак
несохранённых изменений. Каждый экземпляр приложения использует свою копию;
копии ещё работающих экземпляров не предлагаются для восстановления.

При следующем запуске после сбоя приложение предлагает восстановить копию:

- **Да** — восстановить данные, сохранив исходную папку и путь `.omaps`.
  Восстановленный проект остаётся несохранённым; сохраните его вручную.
- **Нет** — удалить предложенную копию.
- **Отмена** — оставить копию до следующего запуска.

Если копия повреждена или восстановлению мешает ошибка каталога, приложение
сохраняет её и показывает сообщение. После успешного восстановления создаётся
копия текущего сеанса, затем удаляется старая.

Обычное закрытие после сохранения или подтверждённого отказа от изменений
удаляет копию текущего сеанса. После ручного сохранения устаревшая копия также
удаляется. При ошибке записи приложение предупреждает один раз за сеанс
и записывает подробности в журнал; ручное сохранение остаётся доступным.
