# Полный сброс локальной БД

1. Закрой приложение, в том числе запущенное из Visual Studio.
2. Открой PowerShell в корне репозитория и выполни:

   ```powershell
   .\scripts\Reset-LocalDatabases.ps1
   ```

3. Запусти приложение. Оно создаст новую БД, структуру таблиц и стандартные формы.

Полный сброс убирает компоненты, семейства, типы, значения НТД, примечания,
варианты значений и учётные записи администраторов. Шаблоны Word и файлы проектов
`.omaps` не затрагиваются. Файлы проектов остаются, но сопоставление компонентов
потребует заново заполненного каталога.

По умолчанию сбрасываются локальные Debug и Release, включая старую
`operationmaps.db`. Для сброса только одной конфигурации:

```powershell
.\scripts\Reset-LocalDatabases.ps1 -Configuration Debug
```

Скрипт рассчитан на текущие пути проекта:
`src/OperationMaps.Wpf/bin/{Debug|Release}/net10.0-windows/`.
Установленные отдельно копии приложения и БД с другим путём подключения
он не изменяет.

## Восстановление

Скрипт переносит исходные файлы БД и сопутствующие файлы SQLite в папку
`artifacts/database-reset-<дата-время>-<идентификатор>` и печатает её полный путь.
Чтобы вернуть данные, закрой приложение, при необходимости снова запусти скрипт
для сохранения уже новой БД, затем скопируй файлы из нужной резервной папки
обратно в соответствующую папку Debug или Release. Сопутствующие файлы
`-wal`, `-shm` и `-journal`, если они есть, нужно переносить вместе с той же БД.
Не смешивай файлы разных резервных копий.
