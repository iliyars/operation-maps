# Примечания при импорте Word

Значение и условие его применения должны быть связаны явно. Например:

```text
Ячейка ресурса: 150000 **
Примечание: ** Используется в облегчённом режиме при U ≤ 0,6 Uном
```

Поддерживаются маркеры `*`, `**`, `***` и далее, вариант `*)`,
числовые ссылки `1)` с определением `1.` или `1)`. Каждое определение
начинается с новой строки; его текст может продолжаться на следующих строках.
Связывается точный маркер: `*` и `**` различаются.

Из значения удаляется только однозначно распознанный маркер. Если в строке
есть неизвестная или неоднозначная ссылка, исходное значение строки сохраняется.
Температурные диапазоны, допуски и номера базовых строк в скобках остаются
частью данных: `(-60 … +85)` и `0,5 (13)` не являются ссылками на примечания.

Импорт компонента требует исправления источника, если:

- Для ссылки не найден текст примечания.
- Один маркер определён несколько раз с разным текстом.
- Примечание не связано ни с одной прочитанной строкой НТД.
- Текст примечания не имеет маркера и его нельзя однозначно привязать.
- Один компонент записан в разных собственных формах, хотя модель каталога
  допускает одну собственную форму компонента.

Ошибки выводятся в окне импорта. Проблемный компонент недоступен для выбора;
сервис записи также отклоняет его. Исправьте Word-файл и откройте его заново.
Другие корректные компоненты можно импортировать отдельно. Ошибки повторных
слотов сохраняются при объединении записей одного компонента.

Однозначно связанные значения облегчённого режима хранятся отдельно от
нормальных вместе с текстом условия. Если нормального значения нет, успешный
импорт не снимает пометку «Необходимо редактирование» — см.
[правила условий](component-regimes.md).

Проверки: `WordNoteParserTests`, `WordCatalogImportServiceTests`,
`Driver741MatchingTests`, `NormalRegimeDataTests`.
