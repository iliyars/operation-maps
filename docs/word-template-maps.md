# Карты заполнения Word

В `Word/Resources/Form*/template.docx` ячейки компонентов должны быть пустыми.
Общие заголовки, названия и номера параметров, рамки и колонтитулы остаются
в шаблоне.

Подписи, относящиеся к одному компоненту, задаются в `componentSlots[].labels`:

```json
"labels": [
  { "row": 4, "col": 2, "text": "в схеме" },
  { "row": 4, "col": 3, "text": "по НТД" }
]
```

`row` и `col` начинаются с 1. Колонка означает физическую ячейку строки:
объединённая ячейка считается одной, независимо от её ширины.
Каждый блок компонента содержит собственный список подписей.
Сюда же относятся «№ выводов» и «Установившийся режим».
Для форм без таких подписей используется `"labels": []`.

Экспорт очищает ячейки компонентов перед копированием таблицы на новые листы
и записывает подписи только для занятых блоков. Незанятые блоки остаются пустыми.

Перед заполнением `WordTemplateValidator` проверяет физические координаты
на исходной таблице: существование таблицы/ячеек и отсутствие записи разных
полей в одну ячейку. Учитываются все слоты, подписи, примечания, условия,
колонки «по НТД»/«в схеме»/«выводы». Дополнительные строки проверяются отдельно:
они вправе повторять колонки основной строки, но их слоты не должны
пересекаться, а строка для копирования должна соответствовать основному параметру.

Проверка экспорта и обзор проекта выполняют эту же проверку в фоне.
Ошибки содержат форму, поле, номер строки и физической ячейки (с 1).
Некорректная карта отклоняется до заполнения документа; исходный шаблон
не изменяется. Все 14 текущих комплектов включены в параметризованный тест.

Это проверка геометрии. Семантику строк по ГОСТ, полноту сидера и пагинацию
в Microsoft Word нужно проверять отдельно.

Проверка всех карт и неполных листов:

```powershell
dotnet test tests/OperationMaps.Tests/OperationMaps.Tests.csproj --filter FullyQualifiedName~EmptyComponentSlotTests
```

Проверка геометрии всех комплектов и некорректных карт:

```powershell
dotnet test tests/OperationMaps.Tests/OperationMaps.Tests.csproj --filter FullyQualifiedName~WordTemplateValidatorTests
```
