# Карты заполнения Word

В `Word/Resources/Form*/template.docx` ячейки компонентов должны быть пустыми.
Общие заголовки, названия и номера параметров, рамки и колонтитулы остаются
в шаблоне.

Подписи, относящиеся к одному компоненту, задаются в `componentSlots[].labels`:

```json
"labels": [
  { "row": 4, "col": 2, "text": "в схеме" },
  { "row": 4, "col": 3, "text": "по НТД" }
]
```

`row` и `col` начинаются с 1. Колонка означает физическую ячейку строки:
объединённая ячейка считается одной, независимо от её ширины.
Каждый блок компонента содержит собственный список подписей.
Сюда же относятся «№ выводов» и «Установившийся режим».
Для форм без таких подписей используется `"labels": []`.

Экспорт очищает ячейки компонентов перед копированием таблицы на новые листы
и записывает подписи только для занятых блоков. Незанятые блоки остаются пустыми.

Проверка всех карт и неполных листов:

```powershell
dotnet test tests/OperationMaps.Tests/OperationMaps.Tests.csproj --filter FullyQualifiedName~EmptyComponentSlotTests
```
