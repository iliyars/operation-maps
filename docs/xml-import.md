# Импорт перечня ПЭ3 XML

Файл должен содержать ровно один элемент `RecordsData` с записями `Record`.
Неподдерживаемая структура, повреждённый XML или неизвестная объявленная
кодировка приводят к сообщению об ошибке; открытый проект сохраняется.

Кодировка читается по правилам XML: объявление `encoding` и BOM.
Проверены Windows-1251, UTF-8 с BOM и без него, UTF-16 с BOM.
Без объявления кодировки и BOM XML считается UTF-8. Для Windows-1251
нужно объявление `encoding="windows-1251"`; кодировка не угадывается.
Поток, переданный импортёру, остаётся открытым.

Записи обрабатываются в исходном порядке:

- Заголовки и сноски (`type_rec="X"`/`"R"`), текстовые примечания
  и ссылки «См.» не являются компонентами.
- Пустое наименование пропускается с предупреждением и исходными позициями.
- Нераспознанный тип и ошибка разбора имени не удаляют компонент:
  исходное имя и позиции сохраняются для сопоставления со справочником.
  В мастере «Ввести данные» можно выбрать существующий тип, если исходный
  тип пустой или отсутствует в каталоге. После заполнения данных компонент
  доступен в проекте и попадает в очередь проверки администратором.
- Отсутствие позиций и повторные позиции внутри одной или разных записей
  отмечаются предупреждениями. Позиции не объединяются и не удаляются
  автоматически; исходный перечень нужно проверить.

После успешного импорта выводятся количество компонентов и предупреждения.
Номер строки в предупреждении — номер записи `Record` внутри `RecordsData`,
начиная с 1, включая заголовки и сноски; это не физическая строка XML-файла.

Тесты: `Pe3XmlImporterTests`, `RealXmlImportTests`, `BackgroundXmlImportTests`
и проверка неизвестного типа в `ComponentMatcherTests`.
